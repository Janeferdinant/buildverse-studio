# BuildVerse Studio — AI Interior Designer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend BuildVerse Studio with an AI-powered interior design workspace that converts real rooms (via 360° panoramas, videos, multi-angle photos, and measured dimensions) into furnished, budget-aware 3D interior designs using purchasable products from Amazon India, Flipkart, IKEA India, and Kerala retailers.

**Architecture:** A modular client-side pipeline integrated seamlessly into BuildVerse Studio:
1. Media Ingestion & 360° Spherical Panoramic Viewer (Three.js Sphere equirectangular projection).
2. Computer Vision / Feature Extraction & Spatial Clearance Engine (detects walls, openings, existing furniture, circulation clearance, collision checks).
3. Real-World Product Catalog with Kerala regional availability, retailer adapters (Amazon, Flipkart, IKEA, Nilambur/Kerala timber craft), and direct purchase URLs.
4. AI Design Generator creating 3 editable alternatives (Budget, Balanced, Premium) with live 3D models, color palettes, and itemized shopping lists.
5. Interactive 3D Room Editor with product replacement, 4-way product comparison, live budget tracking, and CSV/PDF exports.

**Tech Stack:** React 18, TypeScript, Three.js, @react-three/fiber, @react-three/drei, Zustand, Tailwind CSS, Lucide React, Vitest.

**Spec:** Section 2 to 20 of User Master Prompt & `docs/ARCHITECTURE.md`.

## Global Constraints
- Design the user's actual room using real, purchasable products—not imaginary furniture generated by AI.
- Never invent product specifications, reviews, or prices; clearly mark unverified or placeholder data.
- Primary market focus: Kerala, India (INR ₹, delivery to Kochi, Thrissur, Kozhikode, Trivandrum, Kottayam).
- Distinguish observed features, AI-inferred features, user measurements, estimated geometry, and verified dimensions.
- Missing prices and dimensions must be flagged with warning badges and mark estimates as incomplete rather than assuming ₹0.
- Preserve existing CAD workspace, project store, and 3D architectural viewer while adding "AI Room Designer".

## Review Focus
1. **Clearance & Spatial Validation:** Verify walkway clearance (>= 0.8m), door opening swing clearance (>= 0.9m), and bedside clearance (>= 0.6m) with warning badges for tight fits.
2. **Product Replacement Stability:** Replacing a sofa or bed must retain placement coordinates, update 3D dimensions and budget lines, and recalculate clearances.
3. **Equirectangular 360° Panorama Viewer:** Display spherical panoramic images with drag-to-look-around controls without breaking ordinary 3D canvas rendering.
4. **Authentic Provenance & Retailer Links:** Every product must carry retailer tags (Amazon, IKEA, Flipkart, Kerala Local) and direct links without fabricating stock status.
5. **Budget Recalculation:** Live updates to furniture subtotal, finishes, lighting, GST taxes, delivery, and budget remaining gauge against user target budget.
